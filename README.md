
# Customer-Segmentation
This project focuses on analyzing customer shopping behavior using SQL, Python, and Power BI to generate business insights. It identifies product categories for discounts, analyzes customer spending patterns based on age, season, and location, and applies K-Means clustering to segment customers for targeted marketing strategies.

# Customer-Segmentation-Project

## Individual Project
- Harika Hasini Bandaru

## Objective
- Analyze customer shopping trends and segment customers based on purchasing behavior.
- Identify product categories suitable for discounts.
- Analyze spending patterns by age, season, and location.
- Perform customer segmentation using the K-Means clustering algorithm.
- Generate business insights and marketing recommendations.
